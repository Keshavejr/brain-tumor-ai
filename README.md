# 🧠 Brain Tumor Detection AI

An AI-powered web app that detects brain tumors from MRI scans using deep learning models and Grad-CAM visualization.

---

## 🚀 Features
- Multi-class tumor detection (Glioma, Meningioma, Pituitary, No Tumor)
- Dual models (EfficientNet + Custom CNN)
- Grad-CAM heatmap visualization
- Confidence scores & probability breakdown
- PDF report generation
- Modern responsive UI

---

## 🛠️ Tech Stack
- Django (Backend)
- TensorFlow / Keras (ML)
- OpenCV (Image Processing)
- HTML, CSS, JS (Frontend)
